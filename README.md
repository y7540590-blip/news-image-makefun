A program that writes one image summing up the world's news of Tuesday 24 November 2026: a newspaper front page drawn programmatically (PIL, rendered at 2x and downscaled), leading with Jensen Huang's return to Nvidia, NATO's space-defence vow, Russian war dead near 500,000, Israel's rivals clashing over Iran, the US $2.4bn defence package for the Philippines, and the GTA VI hacker jailed in London. main.ts copies the committed entry.png to the output path.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
